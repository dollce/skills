# Skills

재사용 가능한 에이전트 스킬과 유지보수 자료를 관리합니다.

| 스킬 | 용도 | 상태 |
| --- | --- | --- |
| [Splunk SPL Writer](spl/README.md) | 실제 로그 구조에 맞는 최적화된 SPL 생성·제공 | 프리뷰 — CIM 상세 단계는 후속 개발 |

```sh
npx skills add https://github.com/dollce/skills --skill splunk-spl-writer
```

설치·업데이트·삭제 방법은 [SPL 사용 안내](spl/README.md), 다른 세션에서 개발을 이어가는 방법은 [인수인계 문서](spl/MAINTAINER.md)를 참고합니다.
